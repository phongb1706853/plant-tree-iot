Giới thiệu

Plant Tree IoT là hệ thống quản lý vườn cây thông minh dùng ESP32 + .NET + MongoDB. Thiết bị (ESP32) tự chạy chế độ auto theo ngưỡng lưu trong NVS; server chỉ đọc telemetry, đọc/đặt ngưỡng auto (config) và gửi lệnh thủ công (bơm, đèn, chế độ, tin nhắn) xuống ESP32 qua MQTT.

Vì sao MCP không cần expose ra ngoài

MCP protocol mặc định dùng stdio — Ollama UI spawn MCP server làm subprocess, giao tiếp qua stdin/stdout. MCP server bên trong gọi REST API qua HTTPS tunnel. Đây là cách chuẩn MCP, không cần expose port riêng cho MCP.

Chức năng

Devices

  • Đăng ký thiết bị mới với metadata (tên cây, vị trí, plant type)
  • Heartbeat tracking — server biết device nào online
  • List, search device

Sensor Data

  • Upload telemetry (nhiệt độ, độ ẩm, độ ẩm đất %, ánh sáng, áp suất, độ cao, pin, chế độ, trạng thái bơm/đèn, cờ cảnh báo)
  • Payload snake_case đúng hợp đồng (device_id, temperature_c, soil_percent…) — giống hệt telemetry thiết bị publish lên xmini/sensor_data
  • Lấy sensor mới nhất, history, theo khoảng thời gian

Device auto (thiết bị tự chạy)

  • Thiết bị tự chạy chế độ auto dựa trên 15 ngưỡng lưu trong NVS — server KHÔNG sinh lệnh tưới/đèn
  • Muốn đổi hành vi auto → chỉnh ngưỡng (config): GET/PUT /api/control/{deviceId}/config
  • Thiết bị publish cấu hình hiện tại lên xmini/config khi kết nối và sau mỗi lần đổi

Control

  • Gửi lệnh thủ công (ép MANUAL): bơm {"pump":true}, đèn {"light":true}, PWM đèn {"light_pwm":180}
  • Đổi chế độ {"mode":"auto"|"manual"} và hiển thị màn hình TFT {"message":"...","message_secs":N}
  • Server publish khoá phẳng xuống xmini/control; xem nhật ký lệnh đã gửi qua GET /api/control/commands/{deviceId}

Setup mỗi lần chạy

Cảnh báo: Quick Tunnel = URL random, đổi mỗi lần restart cloudflared. Tất cả 4 process đều chạy foreground — đóng terminal là chết.

Thứ tự khởi động (Mac, sau mỗi lần reboot)

1. Mở Docker Desktop

open -a Docker
# Đợi 20–30s, icon cá voi menubar đứng yên

2. Start MongoDB container

docker start mongodb
docker ps    # verify đang Up
# Broker MQTT là HiveMQ Cloud (managed) — không cần start gì cho MQTT

3. Chạy .NET API (Terminal 1 — giữ mở)

cd ~/plant-tree-iot/PlantTreeIoTServer
dotnet run
# Đợi log:
#   "Connected to MQTT broker: ba4fbc53bce842ffb0fcd51178d78414.s1.eu.hivemq.cloud:8883"
#   "Now listening on: http://[::]:8000"

4. Chạy Cloudflare Tunnel (Terminal 2 — giữ mở)

cloudflared tunnel --url http://localhost:8080
# Copy URL "https://xxx-xxx-xxx.trycloudflare.com" từ output
# URL này MỚI mỗi lần chạy — cập nhật mọi nơi dùng

5. Test (Terminal 3)

curl http://localhost:8080/api/devices
# Phải trả về []

curl https://<new-tunnel-url>/api/devices
# Phải trả về [] (test public)

Sync code mới (sau khi sửa server)

# Dừng dotnet (Ctrl+C trong terminal 1)
cd ~/plant-tree-iot
git pull
cd PlantTreeIoTServer
dotnet run

Kịch bản demo

Phần A — IoT team gọi HTTP (5 phút)

Mở Postman / Terminal trên máy Windows, lần lượt:

  1. Đăng ký device ESP32S3_Zone1
  2. Gửi sensor data bằng payload snake_case (giống telemetry thiết bị)
  3. Xem ngưỡng auto hiện tại: GET /api/control/ESP32S3_Zone1/config
  4. Gửi lệnh thủ công bật bơm: POST /api/control/ESP32S3_Zone1 body {"pump":true}
  5. Xem nhật ký lệnh đã publish: GET /api/control/commands/ESP32S3_Zone1

→ Chứng minh: API public, accept payload thiết bị, publish lệnh xuống MQTT real-time.

Phần B — Ollama gọi MCP (5 phút)

Trong Ollama UI đã config MCP server, hỏi tự nhiên:

>>> Liệt kê tất cả thiết bị IoT đang có
>>> Cây ESP32S3_Zone1 hiện tại thế nào?
>>> Bật máy bơm cho cây ESP32S3_Zone1
>>> Đặt ngưỡng tự tưới khi độ ẩm đất dưới 25%
>>> Cho tôi xem 10 lần đo cảm biến gần nhất

→ Chứng minh: AI tự gọi đúng tool MCP, response từ data thật.

Control — Điều khiển thủ công

Gửi lệnh THỦ CÔNG dạng object phẳng. Server publish nguyên khoá phẳng xuống xmini/control (QoS 0). Có thể gộp nhiều khoá trong 1 body. Lệnh chấp hành (pump/light/light_pwm) sẽ ép thiết bị sang MANUAL.

POST /api/control/{deviceId}

Khoá cho phép: pump(bool), light(bool), light_pwm(int 0–255), mode("auto"|"manual"), auto(bool), message(str), message_secs(int), config(object 15 ngưỡng, hoặc {} để yêu cầu gửi lại).

Bật máy bơm (ép MANUAL)

curl -X POST $API/api/control/$DEVICE \
  -H "Content-Type: application/json" \
  -d '{"pump":true}'
Response — HTTP 200
{
  "message": "Command published",
  "deviceId": "ESP32S3_Zone1",
  "published": { "pump": true }
}

Tắt máy bơm

curl -X POST $API/api/control/$DEVICE \
  -H "Content-Type: application/json" \
  -d '{"pump":false}'

Bật / tắt đèn, đặt độ sáng PWM

curl -X POST $API/api/control/$DEVICE -H "Content-Type: application/json" -d '{"light":true}'
curl -X POST $API/api/control/$DEVICE -H "Content-Type: application/json" -d '{"light":false}'
curl -X POST $API/api/control/$DEVICE -H "Content-Type: application/json" -d '{"light_pwm":180}'

Đổi chế độ (auto / manual)

curl -X POST $API/api/control/$DEVICE -H "Content-Type: application/json" -d '{"mode":"auto"}'
curl -X POST $API/api/control/$DEVICE -H "Content-Type: application/json" -d '{"mode":"manual"}'

Code ESP32 mẫu (PubSubClient)


  

    
    
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>

const char* WIFI_SSID     = "<ten-wifi>";
const char* WIFI_PASSWORD = "<mat-khau-wifi>";

const char* MQTT_BROKER   = "ba4fbc53bce842ffb0fcd51178d78414.s1.eu.hivemq.cloud";  // HiveMQ Cloud
const int   MQTT_PORT     = 8883;                // TLS
const char* MQTT_USERNAME = "nod-iot-plant";
const char* MQTT_PASSWORD = "Nod-iot-plant1234";

const char* DEVICE_ID     = "ESP32S3_Zone1";
const char* TOPIC_SENSOR  = "xmini/sensor_data";   // publish telemetry
const char* TOPIC_CONFIG  = "xmini/config";        // publish 15 nguong hien tai
const char* TOPIC_CONTROL = "xmini/control";       // subscribe nhan lenh

WiFiClientSecure wifiClient;                     // TLS bắt buộc cho HiveMQ Cloud
PubSubClient mqtt(wifiClient);

// Nhan lenh: 1 JSON object PHANG, chi cac khoa duoi day (khoa la bo qua)
void onControl(char* topic, byte* payload, unsigned int len) {
  StaticJsonDocument<512> doc;
  if (deserializeJson(doc, payload, len)) return;

  if (doc.containsKey("pump"))      setPump(doc["pump"]);            // ep MANUAL
  if (doc.containsKey("light"))     setLight(doc["light"]);         // ep MANUAL
  if (doc.containsKey("light_pwm")) setLightPwm(doc["light_pwm"]);  // 0-255, ep MANUAL
  if (doc.containsKey("mode"))      setMode(doc["mode"]);           // "auto" | "manual"
  if (doc.containsKey("auto"))      setMode(doc["auto"] ? "auto" : "manual");
  if (doc.containsKey("message"))   showOnTft(doc["message"] | "", doc["message_secs"] | 0);
  if (doc.containsKey("config")) {
    JsonObject cfg = doc["config"].as<JsonObject>();
    if (cfg.size() == 0) publishConfig();          // {"config":{}} = yeu cau gui lai
    else { applyConfig(cfg); saveNvs(); publishConfig(); }
  }
}

void setup() {
  Serial.begin(115200);
  WiFi.begin(WIFI_SSID, WIFI_PASSWORD);
  while (WiFi.status() != WL_CONNECTED) delay(500);

  wifiClient.setInsecure();                        // bỏ verify cert (đủ cho demo)
  mqtt.setServer(MQTT_BROKER, MQTT_PORT);
  mqtt.setCallback(onControl);
  mqtt.setBufferSize(512);
}

void reconnect() {
  while (!mqtt.connected()) {
    if (mqtt.connect(DEVICE_ID, MQTT_USERNAME, MQTT_PASSWORD)) {   // auth HiveMQ Cloud
      mqtt.subscribe(TOPIC_CONTROL, 0);            // QoS 0
      publishConfig();                             // gui 15 nguong hien tai khi ket noi
    } else {
      delay(5000);
    }
  }
}

// Telemetry snake_case PHANG -> xmini/sensor_data
void publishSensor() {
  StaticJsonDocument<384> doc;
  doc["device_id"]        = DEVICE_ID;
  doc["temperature_c"]    = readTemp();
  doc["humidity_percent"] = readHumidity();
  doc["light_lux"]        = readLight();
  doc["soil_percent"]     = readSoilPercent();     // int 0-100
  doc["battery_percent"]  = readBattPercent();
  doc["mode"]             = currentMode();         // "auto" | "manual"
  doc["pump_on"]          = pumpState();
  doc["light_on"]         = lightState();

  char buf[384];
  size_t n = serializeJson(doc, buf);
  mqtt.publish(TOPIC_SENSOR, buf, n);              // QoS 0
}

void loop() {
  if (!mqtt.connected()) reconnect();
  mqtt.loop();

  static unsigned long last = 0;
  if (millis() - last > 10000) {        // ~10s
    publishSensor();
    last = millis();
  }
}

    Cách MCP hoạt động: MCP server không phải một service public — nó là một process Python chạy local, được AI client (Claude Desktop / Ollama UI / Msty / Open WebUI) tự spawn qua stdio khi cần. Troubleshooting MCP setup

  

    
LỗiCách xử lý

    

      AI client không thấy tool
      Check log AI client (Claude Desktop có log ở ~/Library/Logs/Claude/ Mac hoặc %APPDATA%\Claude\logs\ Windows). Thường do đường dẫn Python/server.py sai.
    

    

      ModuleNotFoundError: mcp
      Quên activate venv hoặc pip install -r requirements.txt chưa chạy. Verify lại bằng pytest tests/ -v.
    

    

      Tool gọi nhưng timeout
      Cloudflare Tunnel URL đã đổi — cập nhật config.py với URL mới và restart AI client.
    

    

      "Connection refused" trong log
      Server Mac chưa chạy hoặc tunnel chưa start. Verify: curl https://<tunnel-url>/api/devices phải trả về [].
    

    

      AI không hiểu yêu cầu, không gọi tool
      Đổi model có khả năng tool-calling tốt hơn: Claude (best), GPT-4, llama3.1:70b, qwen2.5:32b. Model nhỏ <7B thường gọi tool kém.
    

    

      Windows: lỗi backslash trong config JSON
      Dùng double backslash \\ hoặc forward slash / trong path JSON.
